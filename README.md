# 🕉️ Akshara Ganapathi Vanarasena Utsava Committee

A responsive and interactive website created for the **Akshara Ganapathi Vanarasena Utsava Committee** to showcase Ganesh Utsav celebrations, events, pooja information, donations, memories, and committee details.

## 🌐 Live Website

Visit the website here:

https://nithin123204-boop.github.io/AGVUC/

---

## ✨ Features

- 🏠 Home page with Ganesh Utsav information
- 📅 Events section
- 🪔 Pooja details
- ❤️ Donation section
- 📱 QR code payment option
- 📝 Donation details form after payment
- 🖼️ Memories Gallery
- 📆 Gallery filtering by year
- 👥 Utsav Committee information
- 📞 Contact section
- 🎨 Attractive and responsive design
- 📱 Mobile-friendly layout

---

## 🛠️ Technologies Used

This website was built using:

- **HTML5** – Website structure
- **CSS3** – Styling, animations, and responsive design
- **JavaScript** – Interactive functionality
- **GitHub Pages** – Website hosting
